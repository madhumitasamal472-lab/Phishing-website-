# Phishing Website Detection using Machine Learning

**Author:** Madhusmita Samal  
**Program:** IBM SkillsBuild Cyber Security Bootcamp 2026 — BharatCares

## Overview
A beginner-friendly Python project that trains a Random Forest model to classify website records as Phishing, Suspicious, or Legitimate using pre-extracted features from the UCI Phishing Websites dataset.

> This model uses dataset features; it does not scan a raw URL or live website.

## Dataset
- UCI Machine Learning Repository: https://archive.ics.uci.edu/dataset/327/phishing
- DOI: https://doi.org/10.24432/C51W2X

## Technologies
Python, pandas, scikit-learn, ucimlrepo, Matplotlib, joblib.

## Run locally
```bash
python -m pip install -r requirements.txt
python Madhusmita_Samal_Phishing_Website_Detection.py
```
An internet connection is needed on the first run to download the dataset.
