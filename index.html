Project Overview

This beginner-friendly project demonstrates how a Random Forest machine-learning model can classify website records as Phishing, Suspicious, or Legitimate, using pre-extracted features from a public dataset.

The Python program downloads the dataset, prepares the data, trains and evaluates the model, and saves evaluation outputs.

Dataset

Dataset: UCI Machine Learning Repository — Phishing Websites.

How to Run the Python Project

  1. Install Python 3.10 or later.
  2. Download the project files from the GitHub repository.
  3. Open a terminal in the project folder.
  4. Install dependencies with python -m pip install -r requirements.txt.
  5. Run python Madhusmita_Samal_Phishing_Website_Detection.py.

Note: GitHub Pages displays this information page. It does not run the Python model in the browser. The Python file must be run in a Python environment.

Project Files

Limitations

The model uses pre-extracted dataset features. It does not directly scan a live website or determine whether a raw URL is safe. Its predictions are educational indicators, not a guarantee of website safety.
